# 01 CPU内部

### 1.主要部件
- **寄存器组**：CPU 内部最快的存储，用来暂存数据、地址、状态。
- **ALU**：执行加减乘除、与或非、移位、比较等运算。
- **控制单元**：取指令、译码、控制各部件按节奏工作。
- **总线**：连接 CPU 内部与外部 Flash、RAM、外设。

### 2.寄存器解析（以 ARM Cortex-M / STM32 为例）
ARM Cortex-M 有 16 个通用寄存器 R0~R15，外加一些特殊寄存器。
##### a.通用寄存器 R0~R12
- 用来存放数据、中间结果、函数参数、局部变量。 
- 运算时，数据通常先从内存加载到这些寄存器，再由 ALU 计算。
##### b.特殊功能寄存器

| 寄存器     | 别名       | 作用                    |
| ------- | -------- | --------------------- |
| R13     | SP       | 栈指针，指向当前栈顶            |
| R14     | LR       | 链接寄存器，保存函数返回地址        |
| R15     | PC       | 程序计数器，指向下一条将要执行的指令的地址 |
| xPSR    | 程序状态寄存器  | 保存 ALU 运算标志、中断状态等     |
| MSP/PSP | 主栈/进程栈指针 | Cortex-M 特有，OS 常用     |
| CONTROL | 控制寄存器    | 选择栈指针、特权级等            |

##### c.程序状态寄存器 xPSR
xPSR 包含几个部分：
- **APSR**：应用程序状态寄存器，含 ALU 标志位：
    - **N**：负标志
    - **Z**：零标志
    - **C**：进位/借位标志
    - **V**：溢出标志
- **IPSR**：中断程序状态寄存器，保存当前异常号。
- **EPSR**：执行程序状态寄存器，如 Thumb 状态位。
这些标志位就是 ALU 运算后产生的，后续条件跳转（如 `BEQ`、`BNE`）会用到。

### 3.ALU 

**ALU（Arithmetic Logic Unit，算术逻辑单元）** 是 CPU 中执行运算的核心部件。它接收操作数，执行运算，输出结果和状态标志。
##### a.ALU 能做什么？
- **算术运算**：加、减、乘、除、增量、减量。
- **逻辑运算**：与 AND、或 OR、非 NOT、异或 XOR。
- **移位**：左移、右移、循环移位。
- **比较**：比较两个数大小，实质是做减法并设置标志位。
- **位操作**：置位、清零、测试位。

##### b.ALU 的输入与输出
- **输入**：
    - 两个操作数（通常来自寄存器，也可能来自立即数）。
    - 控制信号（由控制单元发出，告诉 ALU 做哪种运算）。
- **输出**：
    - 运算结果（写回寄存器或内存）。
    - 状态标志（N、Z、C、V），写入 xPSR。

##### c.ALU 与寄存器的关系
ALU 本身不存储数据，它只是一个“计算电路”。  
数据必须从寄存器（或内存）送进来，算完后再送回寄存器（或内存）。

例如执行 `ADD R0, R1, R2`：
1. 从 R1 和 R2 取出两个数，送到 ALU 输入端。
2. 控制单元告诉 ALU：“做加法”。
3. ALU 算出结果，输出到 R0。
4. 同时根据结果设置 N、Z、C、V 标志。
