# 01 Flash擦/写：解锁，擦除，写入，上锁
1. **解锁**
    - 写密钥到 `FLASH_KEYR`，解除控制寄存器的锁定。
    - 目的：防止程序跑飞误擦写 Flash。
2. **擦除**
    - 选择要擦除的扇区。
    - 启动擦除。
    - 等待忙标志 `BSY` 结束。
    - 检查错误标志。
    - 擦除后该扇区变成 `0xFF`。
3. **写入/编程**
    - 设置编程类型，如字节、半字、字、双字。
    - 把数据写到目标地址。
    - 等待忙标志结束。
    - 检查错误标志。
    - 注意地址对齐和编程单位。
4. **上锁**
    - 设置 `LOCK` 位，重新锁定 Flash 控制寄存器。
    - 防止后续误操作。

---
# 02 为什么必须擦除，不能直接覆盖
因为 Flash 只能从 1 写成 0，不能从 0 写成 1
- **擦除**：把整个扇区/块恢复为 `1`，即 `0xFF`。
- **编程/写入**：只能把某些位从 `1` 变成 `0`。
- **不能通过编程把 `0` 变成 `1`**。

**擦除最小单位是扇区/页/块，不能按字节擦除。**
**编程只能把 `1` 写成 `0`；要把 `0` 变回 `1`，必须先擦除。**

# 03 只修改 Flash 某个扇区中的少量数据时：
1. **备份整个扇区**
    - 读出该扇区全部内容到 RAM 缓冲区。
    - 例如：`memcpy(buf, SECTOR_ADDR, SECTOR_SIZE);`
2. **在 RAM 中修改目标数据**
    - 只改需要改的字节/字。
    - 例如：`buf[offset] = new_value;` 
3. **解锁 Flash**
    - 写/擦前通常需要解锁控制寄存器。
4. **擦除整个扇区**
    - 擦除后该扇区全部变为 `0xFF`。
    - 必须等待擦除完成，检查错误标志。
5. **把 RAM 中修改后的数据写回 Flash**
    - 按编程单位写入，注意地址对齐。
    - 可以写回整个扇区，也可以只写非 `0xFF` 的部分。
    - 写完后检查错误标志。
6. **上锁 Flash**
    - 重新锁定控制寄存器，防止误操作。
```C
uint8_t buf[SECTOR_SIZE];

// 1. 备份整个扇区
memcpy(buf, (void *)SECTOR_ADDR, SECTOR_SIZE);

// 2. 在 RAM 中修改
buf[offset] = new_value;

// 3. 解锁
FLASH_Unlock();

// 4. 擦除整个扇区
FLASH_EraseSector(SECTOR);
while (FLASH_IsBusy());
FLASH_ClearFlags();

// 5. 写回整个扇区
FLASH_Program(SECTOR_ADDR, buf, SECTOR_SIZE);
while (FLASH_IsBusy());
FLASH_ClearFlags();

// 6. 上锁
FLASH_Lock();
```
