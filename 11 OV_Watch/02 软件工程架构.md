# 01 项目整体架构（五层架构）
### 📚 项目整体架构概览
```
OV_Watch/
├── Drivers/       ← CMSIS + HAL 库（官方库，一般不用深究）
├── Core/          ← STM32 HAL 初始化代码（CubeMX生成）
├── BSP/           ← 板级支持包（各种外设/传感器驱动）
├── Middlewares/   ← LVGL 图形库（第三方中间件）
└── User/          ← ⭐ 核心业务逻辑（重点阅读！）
    ├── Tasks/     ← FreeRTOS 各个任务
    ├── GUI_App/   ← LVGL 界面页面
    └── Func/      ← 功能模块（页面管理、数据访问等）
```

### 初始化流程：从 main() 到首屏渲染
**完整时序图**
```
main() @ Core/Src/main.c
│
├─1. SCB->VTOR = 0x0000C000         ← 向量表偏移(配合IAP Bootloader)
│
├─2. HAL_Init()                     ← HAL库初始化(SysTick配置)
│
├─3. SystemClock_Config()           ← 时钟配置: HSI→PLL→100MHz
│     HSI=16MHz, PLLM=8, PLLN=100, PLLP=2 → SYSCLK=100MHz
│     HCLK=100MHz, APB1=50MHz, APB2=100MHz
│
├─4. __enable_irq()                 ← 开启全局中断
│
├─5. MX_GPIO_Init()                 ← GPIO初始化
├─6. MX_DMA_Init()                  ← DMA初始化(SPI1_TX, USART1_RX/TX)
├─7. MX_ADC1_Init()                 ← ADC1初始化(电池电压采样)
├─8. MX_RTC_Init()                  ← RTC初始化(日历+唤醒定时器)
├─9. MX_SPI1_Init()                 ← SPI1初始化(LCD屏幕通信)
├─10. MX_TIM3_Init()                ← TIM3初始化(PWM通道3→LCD背光)
├─11. MX_USART1_UART_Init()         ← USART1初始化(蓝牙通信)
│
├─12. osKernelInitialize()          ← FreeRTOS内核初始化
│
├─13. MX_FREERTOS_Init()            ← ★ 用户任务创建入口
│     └→ User_Tasks_Init()          ← @ user_TasksInit.c
│        │
│        ├─ 创建6个消息队列:
│        │   Key_MessageQueue (按键消息)
│        │   Idle_MessageQueue (变暗请求)
│        │   Stop_MessageQueue (休眠请求)
│        │   IdleBreak_MessageQueue (打断空闲)
│        │   HomeUpdata_MessageQueue (首页刷新触发)
│        │   DataSave_MessageQueue (数据保存触发)
│        │
│        ├─ 创建事件标志组:
│        │   HardIntEventHandle (UART/充电中断→任务通知)
│        │
│        └─ 创建13个任务 (按优先级排列):
│            HardwareInitTask  [High3]  ← 最高优先级，一次性初始化

│            StopEnterTask     [High1]  ← 休眠/唤醒管理
│            IdleEnterTask     [High]   ← 空闲超时→变暗/休眠

│            ScrRenewTask      [Low1]   ← 页面导航
│            SensorDataTask    [Low1]   ← 传感器数据采集
│            HRDataTask        [Low1]   ← 心率数据采集
│            ChargPageEnterTask[Low1]   ← 充电页面切换
│            MessageSendTask   [Low1]   ← BLE协议处理
│            MPUCheckTask      [Low2]   ← 翻腕检测
│            DataSaveTask      [Low2]   ← EEPROM数据保存
│
├─14. osKernelStart()               ← ★ 启动FreeRTOS调度器!
│     │
│     │ 调度器从此开始运行，选择最高优先级就绪任务执行
│     │
│     ▼
│  ┌─────────────────────────────────────────────────────────┐
│  │                HardwareInitTask 开始执行                  │
│  │  @ user_HardwareInitTask.c                              │
│  │                                                         │
│  │  vTaskSuspendAll()  ← 挂起所有其他任务                   │
│  │  │                                                     │
│  │  ├─ RTC唤醒定时器: 2秒周期                              │
│  │  ├─ UART DMA接收: HAL_UART_Receive_DMA(huart1, 25字节)  │
│  │  ├─ 使能UART空闲中断: __HAL_UART_ENABLE_IT(IDLE)        │
│  │  ├─ PWM启动: HAL_TIM_PWM_Start(TIM3_CH3) 背光就绪       │
│  │  ├─ delay_init()               ← 延时函数初始化          │
│  │  │                                                     │
│  │  ├─ 电源初始化: HWInterface.Power.Init()                │
│  │  ├─ 按键初始化: Key_Port_Init()                         │
│  │  │                                                     │
```

#### a. `user_HardwareInitTask.c` (188行) - 硬件初始化（一次性任务）
**硬件初始化流程 → 板子上电做了什么**
这个任务是**第一个运行的高优先级任务**，按顺序初始化：
1. RTC唤醒定时器、UART DMA、PWM背光
2. 电源管理 → 按键 → AHT21温湿度 → LSM303电子罗盘 → SPL06气压计 → MPU6050陀螺仪 → EM7028心率
3. EEPROM读取保存的设置
4. BLE蓝牙模块
5. CST816触摸屏 → ST7789 LCD屏（显示"Welcome!"和版本号）
6. **LVGL初始化** → `lv_init()` → `lv_port_disp_init()` → `lv_port_indev_init()` → `ui_init()`
7. 初始化完成后删除自己

**核心职责**：从上到下逐个初始化所有硬件，最后启动UI
```
// 初始化顺序：
RTC唤醒 → UART DMA → PWM → 电源 → 按键
→ AHT21(3次重试) → LSM303(3次+Sleep) → SPL06(3次)
→ MPU6050(3次) → EM7028(3次+Sleep)
→ EEPROM(读取设置) → BLE(Init+Disable) → 触摸屏复位
→ LCD(显示Welcome+版本号)
→ LVGL init → ui_init → 自毁
```

#### b. `user_RunModeTasks.c` (199行) - 低功耗管理

|函数|行号|职责|
|---|---|---|
|IdleEnterTask|39-80|空闲计时器：10ms递增，到阈值变暗/休眠|
|StopEnterTask|89-199|STOP模式完整流程：  <br>① 关闭外设 → ② 关狗+关SysTick → ③ 进入STOP → ④ 唤醒恢复时钟 → ⑤ 判断唤醒源 → ⑥ 恢复外设+刷新UI|

**STOP模式详解**：
```
进入STOP前:
  HAL_UART_MspDeInit()  关闭UART
  LCD_RES_Clr()         LCD复位
  LCD_Close_Light()     关闭背光
  CST816_Sleep()        触摸屏休眠
  WDOG_Disnable()       关看门狗（STOP会超时）
  CLEAR_BIT(SysTick)    关SysTick
  HAL_PWR_EnterSTOPMode() ← CPU停止，等待RTC/EXTI唤醒

唤醒后:
  SET_BIT(SysTick)      恢复SysTick
  SystemClock_Config()  重配时钟
  HAL_UART_MspInit()    恢复UART
  LCD_Init() + SetLight 恢复LCD
  CST816_Wakeup()       唤醒触摸
  判断唤醒源（按键/充电/抬手）
  → 有效唤醒：首页数据更新
  → 无效唤醒：重新睡眠
```

## 📊 第三条流：任务间通信流（消息队列驱动一切）

**核心问题**：这个系统有14个任务，它们之间怎么协调？为什么 SensorDataTask 不会和 HomePage_timer_cb 抢数据？为什么 IdleEnterTask 知道用户触摸了屏幕？
**关键认知**：FreeRTOS 多任务系统中，**任务之间不直接调用对方的函数**（会破坏调度），而是通过「消息队列 / 事件标志组 / 共享内存」通信。

## 💡 关键学习技巧

1. **画出任务通信图**：`user_TasksInit.c:138-145` 定义了6个消息队列，弄清楚谁往里面发、谁从里面取。
2. **理解LVGL移植层**：在 `Middlewares/LVGL/GUI/lv_port_disp.c` 和 `lv_port_indev.c`（虽然不在User目录，但很关键），看LCD刷屏和触摸输入如何接到LVGL。
3. **BSP层按需阅读**：`BSP/` 目录每个传感器一个子文件夹，用到哪个看哪个：
    - `LCD/` - ST7789驱动
    - `EM7028/` - 心率传感器
    - `MPU6050/` - 陀螺仪+DMP姿态解算
    - `TOUCH/CST816.c` - 触摸芯片
    - `BL24C02/` - EEPROM存储
4. **追踪关键全局变量**：
    - `HWInterface` - 所有硬件数据的统一入口
    - `PageStack` - 页面栈状态
    - `IdleTimerCount` - 空闲计时（决定何时休眠）
