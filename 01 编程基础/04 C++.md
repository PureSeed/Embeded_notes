## 1.2 动态内存管理
```C++
int *p = new int;
int *p = new doouble;
delete p;

int *p = new int[5];
delete[] p;
/* 建议：写完new之后，立刻写delete，然后再写业务代码 */
/* 一般对于占用内存比较大，而且可以用完即删的时候使用 */
```

## 1.3 引用
引用即别名，引用不可修改,创建时就必须初始化（赋值）
```C++
/* 数据类型& 引用名 = 被引用变量 */
int a = 10;
int& b = a;

/* 
 * 值传递：会复制值，无法对实参本身产生影响
 * 地址传参：会复制地址，对实参本身有影响，但是指针写法麻烦
 * 引用传参：像普通变量那样操作，但对实参本身可以产生影响 
 */

```


## 1.4 函数默认值
调用函数的时候不传入参数，则使用函数默认值代替
```C++
void say_hello(const string& msg ="周杰伦")
{
	......
}
/* 每个提供默认值的参数，其右侧参数也必须提供默认值 */
```

# 2. 面向对象编程

## 2.1 类（class）
一个新的结构类，可以封装**属性和行为（函数）**
类就像是一个设计图，而对象就是基于类得到的具体实例
```C++
class class_name
{
public:   // 公开权限，产出的具体对象，可以使用类的成员

private:   // 私有权限，产出的具体对象，不可以使用类的成员。外部调用不了，但是内部的public可以调用

protected:   // 保护权限

}

```
