# 链表
**用数组来存储结构体，结构体中存储一个指向下一个结构体的指针，就是链表。所有说在链表中插入和删除元素只需要改变指针指向的地址。**



# 队列
**后进先出，一种特殊的链表，是只能在队尾执行插入和在队头执行删除操作的链表。** 



# 栈
**后进先出，一种特殊的链表，是只能在栈顶执行插入和删除操作的链表** 
```C
//定义栈
#define MAX_DEPTH 6   
typedef struct {
    Page_t* pages[MAX_DEPTH]; 
    uint8_t top;
} PageStack_t;
------------------------------------------------------------------------------
//初始化栈
static void page_stack_init(PageStack_t* stack) {
    stack->top = 0;   // 初始化栈顶指针为0
}
------------------------------------------------------------------------------
// 新元素进栈
static uint8_t page_stack_push(PageStack_t* stack, Page_t* page) {
    if (stack->top >= MAX_DEPTH)    // 如果栈已满
        return -1;
    stack->pages[stack->top++] = page;  //新元素进栈，上移指针，再赋值
    return 0;
}
------------------------------------------------------------------------------
//出栈
static uint8_t page_stack_pop(PageStack_t* stack) {
    if (stack->top <= 0)
        return -1;
    stack->pages[--stack->top]->deinit();  //销毁栈顶页面的控件
    return 0;
}
------------------------------------------------------------------------------
// 获取栈顶页面的指针
static Page_t* get_top_page(PageStack_t* stack) {
    // 检查栈是否为空
    if (stack->top == 0) {
        return NULL; // 如果栈为空，返回NULL
    }
   // 返回栈顶页面的指针
    return stack->pages[stack->top - 1];

```

### 栈的基本操作
```C
InitStack();  //初始化
DestroyStack();  //销毁
Push   //进栈
Pop   //出栈
GetTop();   //读栈顶元素
StackEmpty();   //栈是否为空
```


# 环形缓冲区
**用数组模拟环形，通过读、写两个指针来模拟环形结构，当指针跑到数组末尾时，就跳回开头继续读写。**
**读、写指针独立移动，互不干扰** 
**解决生产消费速度不匹配的核心方案**
